# Экофиксация

Мобильное PWA для фиксации предполагаемого незаконного сброса сточных вод и подготовки отдельных обращений в четыре ведомства.

## Что делает приложение

- получает координаты телефона и преобразует их в адрес;
- последовательно запрашивает три фотографии;
- стандартизирует источник, место, направление стока и наблюдаемые признаки;
- выбирает адресатов и формирует разные тексты и рекомендуемые темы;
- открывает официальную форму и копирует подготовленный текст;
- локально сохраняет номер отправленного обращения;
- создаёт календарное напоминание на 30-й день.

## Приватность

Фотографии и черновик остаются в браузере телефона. Приложение не получает и не хранит пароль ЕСИА. Финальная отправка выполняется пользователем на официальном государственном портале.

## Локальный запуск

```powershell
npm install
npm run dev -- --host 0.0.0.0
```

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает статическое приложение и публикует каталог `dist`. В настройках репозитория GitHub Pages источником должен быть выбран `GitHub Actions`.
